# Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление  
**Группа:** УНБО-06-25  
**Вариант:** 6

## Описание

Практическая работа по созданию небольшого эмулятора UNIX-подобной
командной строки. Интерфейс сделан на Tkinter.

## Этап 1. REPL

На первом этапе сделано окно с полем ввода и вывода. Парсер понимает
аргументы в кавычках. `ls` и `cd` пока работают как заглушки, также есть
`exit` и вывод ошибок.

## Запуск

```bash
./run.sh
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```
