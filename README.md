# Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление  
**Группа:** УНБО-06-25  
**Вариант:** 6

## Описание

GUI-эмулятор UNIX-подобной командной строки с виртуальной файловой системой
из ZIP-архива. Архив читается в память и при работе программы не изменяется.

## Структура проекта

```text
src/
  main.py       GUI, параметры запуска и стартовые скрипты
  parser.py     разбор команд и аргументов в кавычках
  vfs.py        виртуальная файловая система
  commands.py   команды эмулятора
vfs/            тестовые VFS, создаются локально
scripts/        стартовые скрипты и генератор VFS
os_scripts/     скрипты запуска
tests/          тесты
```

## Этап 1. REPL

Сделан GUI на Tkinter. Заголовок содержит имя VFS. Парсер понимает кавычки,
есть обработка неизвестных команд и неправильных аргументов. На первом этапе
`ls` и `cd` были заглушками, также была команда `exit`.

## Этап 2. Конфигурация

Добавлены параметры `--vfs` и `--script`. Стартовый скрипт поддерживает
комментарии через `#`. При выполнении в окне видно введенную команду и ее
результат.

## Этап 3. VFS

VFS загружается из ZIP без распаковки. Текст хранится как UTF-8, двоичные
данные переводятся в base64. Обрабатываются ошибки отсутствующего файла и
неправильного ZIP.

Тестовые VFS:

```bash
python3 scripts/create_test_vfs.py
```

Создаются `minimal.zip`, `few_files.zip` и `deep.zip`. ZIP-файлы добавлены в
`.gitignore`, поэтому в репозиторий они не попадают.

## Этап 4. Основные команды

Реализованы команды моего варианта:

| Команда | Что делает |
|---|---|
| `ls [путь]` | показывает файлы и папки |
| `cd [путь]` | меняет текущую папку VFS |
| `cat файл` | выводит содержимое файла |
| `tree [путь]` | выводит дерево папок и файлов |
| `whoami` | показывает пользователя ОС |
| `exit` | закрывает программу |

### Пример

```text
vfs:/ $ ls
level1
root.txt
vfs:/ $ cd level1
vfs:/level1 $ cat notes.txt
level one
vfs:/level1 $ tree
/level1
├── level2
│   └── level3
│       └── deep.txt
└── notes.txt
```

## Запуск

```bash
./run.sh --vfs vfs/deep.zip
```

Со стартовым скриптом:

```bash
./run.sh --vfs vfs/deep.zip --script scripts/test_stage4.txt
```

Или:

```bash
./os_scripts/run_stage4.sh
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```
