# Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление  
**Группа:** УНБО-06-25  
**Вариант:** 6

## Описание

GUI-эмулятор UNIX-подобной командной строки с виртуальной файловой системой
(VFS). VFS загружается из ZIP, но сам архив не распаковывается и не меняется.

## Структура проекта

```text
src/          код программы
vfs/          тестовые ZIP VFS, создаются локально
scripts/      стартовые скрипты и генератор VFS
os_scripts/   скрипты запуска
tests/        тесты
```

## Этап 1. REPL

Сделан GUI на Tkinter, парсер с кавычками, ошибки, заглушки `ls`, `cd` и
команда `exit`.

## Этап 2. Конфигурация

Добавлены параметры `--vfs` и `--script`. Стартовый скрипт понимает
комментарии, а команды и результаты отображаются как обычный диалог.

## Этап 3. VFS

VFS загружается из ZIP в оперативную память. Текстовые файлы хранятся как
UTF-8, двоичные данные как base64. Есть обработка ошибок: файл не найден и
неверный ZIP.

Тестовые архивы создаются командой:

```bash
python3 scripts/create_test_vfs.py
```

После этого появятся `minimal.zip`, `few_files.zip` и `deep.zip`. Эти файлы
не добавляются в Git.

## Запуск

```bash
./run.sh
./run.sh --vfs vfs/deep.zip
./run.sh --vfs vfs/deep.zip --script scripts/test_stage3.txt
```

## Скрипты ОС

```bash
./os_scripts/run_vfs_minimal.sh
./os_scripts/run_vfs_few_files.sh
./os_scripts/run_deep.sh
./os_scripts/run_vfs_errors.sh
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```
