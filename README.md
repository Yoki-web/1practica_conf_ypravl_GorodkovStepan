# Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление  
**Группа:** УНБО-06-25  
**Вариант:** 6

## Описание

GUI-эмулятор UNIX-подобной командной строки. Работа разбита на этапы по
методичке. На текущем этапе добавлена настройка приложения через параметры
запуска и стартовые скрипты.

## Структура проекта

```text
src/          исходный код
scripts/      стартовые скрипты
os_scripts/   скрипты запуска в Linux
tests/        тесты
vfs/          тестовые VFS
```

## Этап 1. REPL

Сделано окно на Tkinter, поле ввода и вывода, парсер с поддержкой кавычек,
ошибки, заглушки `ls`, `cd` и команда `exit`.

## Этап 2. Конфигурация

Поддерживаются параметры:

```text
--vfs     путь к VFS
--script  путь к стартовому скрипту
```

Стартовый скрипт пропускает пустые строки и строки, которые начинаются с
`#`. В окне показывается и сама команда, и результат ее выполнения.

## Запуск

```bash
./run.sh
./run.sh --script scripts/test_stage2.txt
```

Или через скрипты ОС:

```bash
./os_scripts/run_stage1.sh
./os_scripts/run_stage2.sh
```

## Тесты

```bash
python3 -m unittest discover -s tests -v
```
