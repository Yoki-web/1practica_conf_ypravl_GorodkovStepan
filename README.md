# Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление  
**Группа:** УНБО-06-25  
**Вариант:** 6

## Описание

GUI-эмулятор UNIX-подобной командной строки с виртуальной файловой системой
(VFS), которая загружается из ZIP-архива. Все изменения VFS происходят только
в памяти программы.

## Структура проекта

```text
src/
  main.py       GUI, параметры запуска и выполнение скриптов
  parser.py     парсер команд с поддержкой кавычек
  vfs.py        виртуальная файловая система
  commands.py   команды эмулятора
vfs/            тестовые ZIP VFS, создаются локально
scripts/        стартовые скрипты и генератор тестовых VFS
os_scripts/     скрипты запуска для Linux
tests/          автоматические тесты
run.sh          обычный запуск программы
```

## Этап 1. REPL

Сделано окно на Tkinter с полем ввода и вывода. Заголовок содержит имя VFS.
Парсер разделяет команду и аргументы и нормально обрабатывает кавычки.
Неизвестные команды и неправильные аргументы выводятся как ошибки.

На первом этапе `ls` и `cd` были заглушками. Также была добавлена команда
`exit`.

Пример аргумента в кавычках:

```text
cd "folder with spaces"
```

## Этап 2. Конфигурация

Программа принимает два параметра:

```text
--vfs     путь к ZIP-файлу VFS
--script  путь к стартовому скрипту
```

Стартовый скрипт выполняет команды по порядку. Пустые строки и строки,
которые начинаются с `#`, считаются комментариями и пропускаются. Во время
работы в окне видно команду и результат ее выполнения.

## Этап 3. VFS

VFS загружается из ZIP напрямую в оперативную память. Архив не распаковывается
в отдельную папку и не изменяется. Обычные текстовые файлы хранятся как UTF-8,
а двоичные данные переводятся в base64.

Обрабатываются две ошибки загрузки:

- файл VFS не найден;
- файл не является ZIP-архивом.

Тестовые VFS создаются так:

```bash
python3 scripts/create_test_vfs.py
```

Будут созданы:

```text
vfs/minimal.zip
vfs/few_files.zip
vfs/deep.zip
```

ZIP-файлы указаны в `.gitignore`, поэтому в Git они не добавляются.

## Этап 4. Основные команды

Для варианта 6 реализованы:

| Команда | Описание |
|---|---|
| `ls [путь]` | показать содержимое каталога |
| `cd [путь]` | сменить текущий каталог VFS |
| `cat файл` | вывести содержимое файла |
| `tree [путь]` | показать дерево VFS |
| `whoami` | показать пользователя реальной ОС |
| `exit` | закрыть эмулятор |

Пример:

```text
vfs:/ $ ls
level1
root.txt
vfs:/ $ cd level1
vfs:/level1 $ cat notes.txt
level one
vfs:/level1 $ tree
/level1
├── level2
│   ├── info.txt
│   └── level3
│       └── deep.txt
└── notes.txt
```

## Этап 5. mv

Добавлена команда:

```text
mv источник назначение
```

Она может переименовать файл или каталог либо переместить его в другую
виртуальную папку. Меняется только состояние VFS в памяти. Исходный ZIP на
диске остается таким же.

Пример:

```text
vfs:/ $ mv root.txt renamed.txt
vfs:/ $ ls
level1
renamed.txt
vfs:/ $ mv renamed.txt level1
vfs:/ $ ls level1
level2
notes.txt
renamed.txt
```

## Запуск

Сначала можно создать тестовые VFS:

```bash
python3 scripts/create_test_vfs.py
```

Обычный запуск:

```bash
./run.sh --vfs vfs/deep.zip
```

Запуск со стартовым скриптом:

```bash
./run.sh --vfs vfs/deep.zip --script scripts/test_stage5.txt
```
